# XRPL Lending Monitor

Read-only monitoring, history, and audit tooling for the XRPL Lending Protocol.

The project will cover the normal monitoring surface expected from a lending dashboard—overview, vaults, loan brokers, loans, activity, search, and network status—while preserving full lifecycle history, deleted objects, state transitions, first-loss cover changes, and Devnet epochs.

## Current status

Project foundation and source-of-truth documentation are being established before collector and UI implementation.

All implementation must follow the repository specifications and development roadmap under `docs/`. Contributors and coding agents must read `AGENTS.md` before making changes.
