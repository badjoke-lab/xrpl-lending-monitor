# Resource envelope

## Purpose

The DB-less architecture still requires explicit resource limits. Free operation is a target, not an assumption.

## Hard architectural limits

- no Cloudflare D1/Queue/KV/R2/Durable Objects;
- no Supabase canonical store;
- no browser full scan of XRPL Current state;
- no browser download of the full multi-million-object Current dataset;
- no five-minute generated-data Git commits;
- no request-time full-history aggregation.

## Known scale evidence

The verified 2026-09-11 fresh Current build at ledger 5,218,039 produced:

- Vaults: 1,234,169;
- LoanBrokers: 776,954;
- Loans: 339,744;
- total relevant objects: 2,350,867;
- read-model page size: 50;
- Vault pages: 24,684;
- LoanBroker pages: 15,540;
- Loan pages: 6,795.

This evidence invalidates a browser-side full Current scan design.

The retained historical generation covers 560,626 ledgers and 1,136 history segments through ledger 3,932,301.

## Budgets to qualify before cutover

The migration must measure and set explicit pass/fail limits for:

- fresh-base elapsed time;
- fresh-base generated bytes;
- largest release asset;
- five-minute collector elapsed time;
- XRPL request count;
- typical and worst-case delta bytes;
- compaction elapsed time and bytes rewritten;
- live channel bytes;
- Overview initial requests/bytes;
- list initial requests/bytes;
- exact detail lookup requests/bytes;
- Activity requests/bytes;
- one history detail requests/bytes;
- browser memory on representative desktop/mobile;
- GitHub Actions execution frequency and storage growth.

Unknown limits are recorded as **unqualified**, not filled with legacy D1 numbers.

## Browser read rule

Every normal route must have a bounded query plan independent of total historical age.

Exact Current lookup must be O(1) or bounded-shard lookup from published indexes.

List pages must use precomputed pages/indexes.

History detail must use exact/bucket indexes or bounded segment references.

## Growth rule

Live deltas cannot grow without compaction.

Before production cutover, measurement must establish:

- maximum active delta count or equivalent overlay generation size;
- compaction cadence trigger;
- retention rule for superseded live artifacts;
- retention rule for immutable historical artifacts.

## Failure headroom

A run that approaches a provider, runner, memory, asset-size, or execution-time ceiling must fail before publishing the channel.

Reducing verification or silently skipping ledgers is not a valid resource response.
