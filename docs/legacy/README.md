# Legacy material policy

The active repository documentation was reset on 2026-09-20 for the DB-less architecture.

Obsolete Cloudflare D1/Queue/Worker-Cron, Supabase R4/R5 recovery, M6 pre-pivot, and related operational plans are intentionally removed from the current documentation tree.

They remain recoverable through Git history.

## Rule for future work

Do not inspect or use deleted historical documents during normal implementation.

Historical material may be consulted only when a task explicitly asks for:

- incident forensics;
- provenance reconstruction;
- regression comparison;
- recovery of a specific reusable algorithm or evidence item.

When historical material conflicts with current source-of-truth documents, current documents win.
